# Conditional Statements in Python: Finding Eligible person to vote

## 🎯 Aim
To write a Python program to check whether the given person's age is **Eligible** or **Not Eligible** to Vote using `if...else` statements.

## 🧠 Algorithm
1. Get an input from the user.
2. Convert the input to an integer and store it in a variable `a`.
3. Use the Comparison operator `>=` to check if `a >= 18`.
   - If true, print `"Eligible"`.
   - Else, print `"Not Eligible"`.
4. End the program.

## 🧾 Program
a=int(input())
if a>=18:
    print("Eligible")
else:
    print("Not Eligible")
